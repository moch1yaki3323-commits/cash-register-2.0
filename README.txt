收銀機｜完整上傳版 v2

直接把本資料夾裡的「所有檔案」上傳到 GitHub repository 根目錄即可。
index.html 必須在最外層。

這版重點：
- Day 1～5 改成日期（日曆）＋場次名稱
- 可新增、切換、編輯、刪除場次
- 所有場次共用實體庫存；訂單與統計依場次分開
- 購物車只有加入第一個商品後才出現，並可自由收起／展開
- 付款區只留一個「結帳」按鈕
- 結帳後再選：現金／街口／轉帳／LINE Pay
- 轉帳、LINE Pay 可在裝置上自行上傳 QR 圖片
- QR 圖片儲存在該裝置瀏覽器的 IndexedDB，不會上傳到 GitHub
- QR 會放在統一的漂亮卡片中顯示，不會直接把原圖突兀貼上
- 低庫存 1～5 顯示莫蘭迪紅
- 0 庫存顯示 SOLD OUT、按鈕變暗且不能點
- 保留商品庫、拍立得署名、自訂常駐品項、自訂拍立得、CSV、統計
- iPhone / iPad / 電腦支援


新增｜掛軸競標
- 商品庫可開啟／關閉掛軸競標
- 可設定競標名稱、目前金額、開始時間、結束時間
- 開啟後會固定顯示於收銀機上方
- 未開始：顯示「還沒開始」並倒數至開始
- 競標中：顯示「競標進行中」並倒數至結束
- 已結束：顯示「競標已結束」
- 目前金額由工作人員手動更新
- 上方競標列可直接按「更新金額」快速修改


競標更新 v4
- 狀態用詞改為：尚未開始／競標中／競標結束
- 新增「每標加價」設定
- 上方競標列會顯示每標加價金額
- 快速更新競標金額時可直接按「＋一標」
- 加強 iPhone / iPad Safari 藍字修正


付款方式更新 v5
- 街口改成和轉帳／LINE Pay 一樣，可直接在裝置上自行上傳 QR 圖片
- 街口、轉帳、LINE Pay 都可在「商品庫 → 付款方式設定」自由開啟／關閉
- 現金固定保留
- 關閉的付款方式不會出現在結帳付款選單
- QR 圖片仍只保存在該裝置瀏覽器，不會上傳 GitHub


競標更新 v7
- 競標金額欄位明確改為「可自由輸入」
- 快速更新時可以直接輸入任意金額
- 「＋一標」僅為快速加價，不會限制手動輸入金額


QR 更新 v8
- 街口／轉帳／LINE Pay 改為「上傳 QR」
- 從相簿或檔案選擇包含 QR 的圖片
- 系統會自動辨識 QR 並裁切，只留下 QR 本體與必要白邊
- 不再顯示截圖裡其他畫面
- QR 本體周圍取消裝飾框
- QR 仍儲存在該裝置，不會上傳 GitHub


競標更新 v10
- 新增「目前署名」欄位
- 一般競標設定與快速更新都可以修改署名
- 競標進行中會在金額下方顯示目前署名
- 競標時間結束後，若有署名會顯示「恭喜 XXX 得標」


競標更新 v12
- 主頁不再顯示競標開始／結束時間
- 時間仍保留在競標設定內
- 尚未開始時仍顯示開始時間
- 競標開始後主頁只顯示距離結束倒數
