收銀機｜完整上傳版 v2

直接把本資料夾裡的「所有檔案」上傳到 GitHub repository 根目錄即可。
index.html 必須在最外層。

這版重點：
- Day 1～5 改成日期（日曆）＋場次名稱
- 可新增、切換、編輯、刪除場次
- 所有場次共用實體庫存；訂單與統計依場次分開
- 購物車只有加入第一個商品後才出現，並可自由收起／展開
- 付款區只留一個「結帳」按鈕
- 結帳後再選：現金／街口／轉帳／LINE Pay
- 轉帳、LINE Pay 可在裝置上自行上傳 QR 圖片
- QR 圖片儲存在該裝置瀏覽器的 IndexedDB，不會上傳到 GitHub
- QR 會放在統一的漂亮卡片中顯示，不會直接把原圖突兀貼上
- 低庫存 1～5 顯示莫蘭迪紅
- 0 庫存顯示 SOLD OUT、按鈕變暗且不能點
- 保留商品庫、拍立得署名、自訂常駐品項、自訂拍立得、CSV、統計
- iPhone / iPad / 電腦支援


新增｜掛軸競標
- 商品庫可開啟／關閉掛軸競標
- 可設定競標名稱、目前金額、開始時間、結束時間
- 開啟後會固定顯示於收銀機上方
- 未開始：顯示「還沒開始」並倒數至開始
- 競標中：顯示「競標進行中」並倒數至結束
- 已結束：顯示「競標已結束」
- 目前金額由工作人員手動更新
- 上方競標列可直接按「更新金額」快速修改


競標更新 v4
- 狀態用詞改為：尚未開始／競標中／競標結束
- 新增「每標加價」設定
- 上方競標列會顯示每標加價金額
- 快速更新競標金額時可直接按「＋一標」
- 加強 iPhone / iPad Safari 藍字修正


付款方式更新 v5
- 街口改成和轉帳／LINE Pay 一樣，可直接在裝置上自行上傳 QR 圖片
- 街口、轉帳、LINE Pay 都可在「商品庫 → 付款方式設定」自由開啟／關閉
- 現金固定保留
- 關閉的付款方式不會出現在結帳付款選單
- QR 圖片仍只保存在該裝置瀏覽器，不會上傳 GitHub


競標更新 v7
- 競標金額欄位明確改為「可自由輸入」
- 快速更新時可以直接輸入任意金額
- 「＋一標」僅為快速加價，不會限制手動輸入金額


QR 更新 v8
- 街口／轉帳／LINE Pay 改為「上傳 QR」
- 從相簿或檔案選擇包含 QR 的圖片
- 系統會自動辨識 QR 並裁切，只留下 QR 本體與必要白邊
- 不再顯示截圖裡其他畫面
- QR 本體周圍取消裝飾框
- QR 仍儲存在該裝置，不會上傳 GitHub


競標更新 v10
- 新增「目前署名」欄位
- 一般競標設定與快速更新都可以修改署名
- 競標進行中會在金額下方顯示目前署名
- 競標時間結束後，若有署名會顯示「恭喜 XXX 得標」


競標更新 v12
- 主頁不再顯示競標開始／結束時間
- 時間仍保留在競標設定內
- 尚未開始時仍顯示開始時間
- 競標開始後主頁只顯示距離結束倒數


競標更新 v13
- 競標結束後自動保存競標紀錄
- 紀錄內容：日期、場次、競標品、得標署名、最終金額、結束時間
- 競標紀錄顯示在商品庫內
- 競標結束隔天會自動關閉，不會一直掛在主頁
- 商品庫新增「關閉競標」按鈕，可手動關閉
- 競標結束時主頁改成置中、大字、粗體顯示「恭喜 XXX 得標」
- 下方同時顯示最終得標金額


版面更新 v14
- 購物車展開時，競標條會自動縮成和左側商品欄同寬
- 購物車會維持右側獨立欄，不會被競標條壓住
- 購物車收起後，競標條恢復全寬
- 手機／窄螢幕維持全寬顯示


QR 更新 v15
- 不再使用自動 QR 辨識
- 上傳圖片後會直接進入手動裁切
- 可拖曳圖片、滑桿縮放，把 QR 放進白色方框
- 儲存後只保留白色方框內的正方形 QR 區域
- 不需要系統辨識，所以截圖、付款頁、各種 QR 圖都可使用


競標更新 v16
- 新增主頁「關閉競標」按鈕
- 競標結束畫面也有「關閉競標」按鈕
- 關閉競標後自動清除：
  • 目前署名
  • 目前競標金額
  • 開始時間
  • 結束時間
  • 競標狀態
- 每標加價回到預設 NT$100
- 競標名稱回到「掛軸競標」
- 已完成的競標紀錄仍會保留
- 隔天自動關閉時也會套用同樣的完整歸零


競標更新 v17
- 每次「更新金額」都會清空署名欄位
- 更新金額時必須重新輸入署名，不能空白
- 開啟競標時署名也設為必填
- 開始時間、結束時間新增「當下時間」按鈕
- 競標時間統一整理成 5 分鐘一格
- datetime-local 使用 300 秒 step，並在儲存前再次自動校正


競標更新 v20
- 「當下時間」按鈕改名為「現在」
- 結束時間新增快速選擇：1 / 2 / 3 / 4 小時後
- 可自訂幾小時後結束
- 幾小時後以「競標開始時間」為基準；若未填開始時間，則以現在為基準
- 計算後仍自動整理成 5 分鐘一格


實戰功能 v21
- 結帳完成後顯示大型完成提示
- 可複製上一筆訂單到購物車
- 場次統計新增各付款方式累計卡片
- 低庫存警示門檻可設定預設值，也可針對單一商品覆寫
- 競標新增起標價
- 競標每次更新「署名＋金額＋時間」都會留下出價紀錄
- 競標結束紀錄也會保存完整 bidHistory
- 新增收攤摘要與關閉競標流程
- 新增完整 JSON 備份／還原，包含 localStorage 與街口／轉帳／LINE Pay QR 圖片


轉帳更新 v22
- 付款方式設定新增銀行名稱、銀行代碼、轉帳帳號
- 轉帳付款頁自動顯示「XX銀行 (XXX) XXXXXXXXXXXX」
- 點帳號資訊可直接複製純帳號
- 手續費說明改為「跨行轉帳可能依各家銀行規定產生手續費，請勿從應付金額中扣除。」
- 原本 QR 上傳／裁切功能保留


競標歷史更新 v23
- 競標歷史改成依日期分組顯示
- 每個日期顯示該日競標筆數
- 日期內再列出場次、競標品、得標署名、最終金額、結束時間
- 新增「清除競標歷史」按鈕
- 清除前會再次確認，避免誤刪


抽抽樂更新 v24
- 商品庫新增「抽抽樂獎項管理」
- 可自由新增獎項，不綁死 SP/A/B/最後賞
- 每個獎項可設定剩餘數量、低量提醒門檻、手動完售
- 可用 −1 / ＋1 快速調整
- 抽抽樂收銀頁會自動顯示「XX賞 已完售」或「XX賞 剩餘 N」
- 獎項管理與抽數庫存互相獨立，方便現場手動追蹤


生寫真更新 v28
- 「公式服」固定為預設款式，不可刪除
- 其他生寫真款式可自由保留或刪除
- 生寫真選擇頁新增「＋」按鈕，可現場新增款式
- 商品庫的生寫真庫存區也新增「＋ 新增生寫真款式」
- 新增款式時可直接設定庫存；留空為不限量
- 舊「公式款」資料會自動轉成「公式服」


場次獨立設定 v29
- 每個場次各自記住一般商品設定與庫存
- 每個場次各自記住生寫真款式與庫存
- 每個場次各自記住拍立得選項與庫存
- 每個場次各自記住抽抽樂起始抽數、獎項、提醒
- 每個場次各自記住付款方式開關
- 每個場次各自記住庫存警示門檻
- 每個場次各自記住競標設定與進度
- 新建場次會複製目前場次的設定作為起點，之後互不影響
- 切回舊場次會載回該場次自己的設定
- 銀行名稱／代碼／帳號與付款 QR 圖片維持全站共用
- 刪除場次時會一併刪除該場次的獨立設定資料


排版修正 v30
- 修正 iPad / iPhone 競標時間欄位與「現在」按鈕重疊
- 所有 modal 輸入欄位強制限制在容器寬度內
- iOS datetime-local 欄位補上 min-width / width 修正
- 「幾小時後結束」改成響應式格狀排列
- 手機版 modal 改為可安全捲動，底部操作按鈕固定在可視區
- 小螢幕進一步縮小間距與按鈕寬度


競標清除修正 v31
- 修正「清除競標歷史」後，已結束競標又被自動寫回歷史的問題
- 清除後會記住該筆已被使用者清除，不會立刻重新出現
- 新增「清除目前出價紀錄」按鈕
- 清除目前出價紀錄只清署名/金額歷程，不會改目前競標金額與目前署名
- 新開一輪競標後仍可正常建立新的競標歷史


競標清除修正 v32
- 「清除競標歷史」改成強制刪除 localStorage 競標歷史資料
- 清除後會顯示「競標歷史已清除」
- 已結束且仍掛著的目前競標會同步關閉並歸零，避免同一筆再次自動寫回
- 已清除競標 ID 改為全站共用記錄，因此切換其他場次也不會把舊歷史重新寫回
- 新開一輪競標時，仍會正常建立新的歷史紀錄


價格更新 v33
- 一般商品全部可自由修改價格
- 固定商品也可以改價
- 拍立得每個選項可個別修改價格
- 生寫真新增「統一價格」開關
- 開啟統一價格：所有生寫真款式套用同一價格
- 關閉統一價格：每個款式可個別修改價格
- 電子檔加購金額也可自行修改
- 新增生寫真款式時可直接設定價格
- 各場次仍各自記住自己的價格設定


後台整理 v34
- 商品庫全面改為一致的分類卡片格式
- 一般商品／生寫真／拍立得／抽抽樂都在分類標題右側提供「＋ 新增」
- 一般商品後台新增時會直接建立常駐商品，不會加入目前購物車
- 拍立得後台新增時會直接建立常駐選項，不會跳到署名流程
- 生寫真移除表格底部重複的新增列，改為分類標題右側新增
- 抽抽樂的起始抽數與獎項管理整併在同一區
- 付款方式、競標、其他設定各自獨立分區
- 手機／iPad 表格改為橫向滑動，避免欄位擠成一團


價格編輯更新 v35
- 一般商品：價格欄直接輸入修改，不再按「價格」按鈕
- 生寫真：每款價格欄直接輸入修改
- 拍立得：每個選項價格欄直接輸入修改
- 抽抽樂：後台直接提供「每抽價格」輸入框
- 生寫真標題旁新增小型「統一價格」勾選
- 拍立得標題旁新增小型「統一價格」勾選
- 勾選統一價格後，修改任一價格會同步套用整個分類
- 電子檔加購金額維持獨立直接輸入


版面與排序更新 v36
- 一般商品、生寫真、拍立得、抽抽樂的新增按鈕統一放在表格最下方
- 新增列改成小型灰色按鈕，視覺比照「＋ 新增生寫真款式」
- 商品庫分類重新排序：一般商品 → 生寫真 → 拍立得 → 抽抽樂 → 庫存提醒 → 付款方式 → 競標 → 資料管理
- 資料管理固定放最後
- 競標歷史移至「場次統計」，只顯示目前場次的競標紀錄
- 商品庫的競標區只保留競標設定與目前出價紀錄
- 收銀主頁開啟「管理」後，每張商品卡新增 ← / →，可自由調整顯示順序
- 商品排序會跟目前場次一起保存


活動彈性設定 v39
- 新增「歸屬設定」：每場次可自由新增、改名、開關、刪除成員／分組
- 場次統計的人名卡片不再固定，只顯示後台開啟的歸屬
- 一般商品的歸屬改為後台自訂下拉選單
- 生寫真每款可各自指定歸屬
- 拍立得每個選項可各自指定歸屬
- 新增一般商品與新增拍立得時，歸屬選單會自動使用目前場次設定
- 付款方式新增「現金」開關
- 結帳頁與場次統計付款框都只顯示目前場次有開啟的付款方式
- 收攤摘要也只列出本場開啟的付款方式


歸屬與後台排版 v40
- 商品庫所有內層設定區塊統一加邊框，抽抽樂、資料管理、付款、庫存提醒等不再浮在背景上
- 「活動歸屬／成員」移到商品庫最上方，並加明確說明
- 可用「＋ 新增其他人／分組」新增任意人員
- 每個歸屬可改名、統計開關、刪除；阿芽咪等預設成員也可刪
- 一般商品與生寫真維持單一歸屬下拉
- 拍立得取消表格下拉，改成「設定歸屬」按鈕
- 拍立得歸屬改為核取方塊複選，可同時選多人
- 新增拍立得時也可直接複選多人
- 拍立得若選多人，場次統計會把該筆金額平均分配給所選歸屬，避免營業額重複計算


排版／預設資料更新 v41
- 資料管理：完整備份 JSON、還原備份改成各自獨立框
- 抽抽樂：修改抽數、每抽價格改成各自獨立框
- 新場次不再預設麻糬燒 Yaki、阿芽咪 Ayami、雙人
- 拍立得不再預設上述三個固定選項
- 預設商品不再綁定「雙人」歸屬
- 舊版若仍是完全未修改的三個預設成員／三個預設拍立得，首次開啟新版會自動清除
- 使用者自行修改或新增過的人員資料不會被自動刪除


隸屬完全無預設 v42
- 商品／生寫真／拍立得的隸屬下拉不再預設麻糬燒 Yaki、阿芽咪 Ayami、雙人
- 下拉只會顯示「活動歸屬／成員」中由使用者自行建立的項目
